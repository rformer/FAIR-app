# F-014 Distribution, installer & licensing — Tasks
Status: **Approved** (Robert Former, 2026-11-26) | Design: Approved 2026-11-26

Sizing: S ≤ 1 day · M = 2–3 days · L = up to 1 week (split when picked up).
Prerequisites:
- F-012: the signed release (images, SBOMs, signatures, provenance, `release-manifest.json`, `cosign.pub`, `SHA256SUMS`), `internal/fleet` and `releasegen fleet`, `scripts/verify-release.sh`, `TestUpgradeFromPreviousReleases`, the image matrix. T-07's dry run (`v0.0.0-test`) is still open; F-014's release jobs join it.
- F-015: the deployment check catalog (`internal/scanner/checks`) and its distribution fixtures, `posture seed`, `posture k8s-access`, exceptions, the POA&M and Assessment Results exports.
- F-001: `iam keys`, `iam migrate`, `iam breakglass`, `scripts/db-bootstrap.sh`. F-002: `objstore`, the Verifier, `fair-audit-verify`, archives and holds. F-010: the PDF/UA writer.

Rules for every task:
- No test reaches the vendor, a cloud or the internet; install tests run on kind (and RKE2 and MicroShift in the install matrix) with local registries.
- No secret in output, values, Helm release records, ConfigMaps, reports, logs or fixtures; generated secrets come from the FIPS module.
- Every new binary is built with `GOFIPS140=v1.0.0`; every new image joins the image matrix; every new action, image or dependency is pinned.
- A design change found while implementing is proposed to Robert Former and recorded in the design's Change Log before it is built.
